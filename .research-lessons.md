## Research Strategy

- **System-level audits find the highest-impact issues.** Cycle 15's integration audit found the #1 problem (nothing wired) that 5 prior code-level cycles missed entirely.
- **Cycle 27 system-level audit found 2 criticals code-level missed.** Discord channels hardcoded empty (entire ingest path broken) and getLatestReport race (reports created but never delivered). Both invisible to code-level audits.
- **Alternate system-level and code-level research.** Code-level finds bugs; system-level finds "it doesn't work at all." Both are necessary.
- **Comparing code vs docs is high-yield.** Cycle 2 found 5 critical/high issues by diffing code against PIPELINE.md, QUERIES.md.
- **Comparing code vs schema is equally high-yield.** health.ts had 4 broken SQL issues found this way.
- **Tracing data flow end-to-end catches integration gaps.** The INSERT-then-SELECT-latest pattern in report delivery was only visible when tracing the full flash/daily/pulse paths.
- **Reading error handling paths (catch blocks) finds more than scanning for missing try/catch.**
- **Testing actual imports vs test assertions catches phantom tests.** Always check import statements.
- **Targeted deep-dives on previously-audited modules still pay off.**
- **Identify systemic cross-cutting issues.** Timezone handling emerged as a pattern affecting multiple files.

## Agent Tuning

- **Dynamic agents > fixed roles.** Cycle 16 used 5 custom agents (wiring, server, security, bugfix, summarize) — none from a predefined table. Each got a brief tailored to the exact task.
- **One agent per file avoids merge conflicts.** Cycle 16 had 0 conflicts across 8 files.
- **Wiring agent needs full context.** Give it ALL factory signatures upfront — don't make it discover them.
- **Security fixes pair well.** IPv6 + diacritical bypass were unrelated but same agent handled both efficiently.
- **6-agent system-level research scales well.** Cycle 27 used 6 agents (ingest→summary, summary→report, pulse/narrative/embed, auth/dashboard, health/recovery, entity lifecycle). All returned quality findings. No duplication issues.
- **End-to-end trace agents find more than module-scoped agents.** Giving an agent a full data path (ingest→normalize→summarize) found the Discord stub that module-scoped audits missed.
