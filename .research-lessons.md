## Research Strategy

- **Never idle when there are unaudited areas.** Cycle 39's deep dive found 50+ issues. Previous idle cycles were wrong.
- **Target the least-audited modules for maximum yield.** Chat, ops, webhook, normalize had the most critical bugs.
- **Batch medium fixes efficiently.** Cycles 42-43 resolved 21 mediums in 2 commits with 10 parallel agents.
- **System-level audits find integration bugs code-level misses.** Cycle 63 found CH-001 (wrong column) and CF-002 (CHECK constraint).
- **LLM wrapper has subtle retry/backoff issues.** Cycle 66 found timeout non-retry (LM-008), aggressive backoff (LM-002), and cost validation gap (LM-004). These have been stable for 24 cycles — easy to miss.
- **RSS ingest never had a dedicated audit.** Cycle 66 found XXE risk (RS-001) and SSRF on feed URL (RS-002). Important for security.
- **Embedder has broken retry-after parsing.** EM-007 means Gemini 429 always uses 60s default regardless of server preference.
- **Auth system is mostly sound.** Cycle 66 found OAuth state reuse (AU-007) and session limit race (AU-010) but no critical auth bypasses.
- **Semantic search has a fundamental vector mismatch.** Cycle 71 found CS-001: embed-pipeline prepares text with type prefix but chat search embeds raw query. This silently degrades all search results. Highest-impact find since CH-001.
- **Cycle 73: Regression tests for cycle 72 fixes.** 12 new tests across 5 files (chat-tools, health, webhook, entities, scheduler). Structural test pattern works well for pipeline ordering (SD-005) — reads source and asserts call positions.
- **Cycle 72: Largest single-cycle fix batch.** 1 critical + 8 high in one commit with 7 parallel agents. All succeeded. Migration 9 adds retry_count column. Test updates needed for interface changes (prepareText on Embedder, atomic content_anchor, retry CASE query).
- **Agent false positives need verification.** Cycle 71: SD-003 (decrementDate timezone) was a false positive — function operates on date strings already in correct timezone. DP-002 (maxTokens) was overstated — 300 per compressed summary is reasonable. Always verify critical findings before queuing.
- **Pipeline ordering matters.** SD-005: narratives are detected after daily synthesis, so daily reports never include narrative context. This is a design-level issue, not a code bug — easy to miss in code-level audits.
