## Research Strategy

- **Never idle when there are unaudited areas.** Cycle 39's deep dive found 50+ issues. Previous idle cycles were wrong.
- **Target the least-audited modules for maximum yield.** Chat, ops, webhook, normalize had the most critical bugs.
- **Batch medium fixes efficiently.** Cycles 42-43 resolved 21 mediums in 2 commits with 10 parallel agents.
- **Pre-summarize is under-audited.** Cycle 60 found critical nonce wrapping gap + 5 high issues. Never had a dedicated audit before.
- **Correlator + synthesize have intertwined timezone bugs.** Three separate findings (CR-001, SP-003, SP-004) share the same root cause: inconsistent time window handling. Fix together.
- **Entity resolution has race conditions under concurrent polling.** SD-002 and SD-003 are related — both involve concurrent writes to entities table without proper locking.
- **System-level audits find integration bugs code-level misses.** Cycle 63 found CH-001 (wrong column name in chat search — functional bug invisible at code level) and CF-002 (CHECK constraint vs code mismatch).
- **Dashboard build not integrated with root build.** DB-001 means production deploys have no frontend — critical deploy bug found only by tracing the full build path.
