## Research Strategy

- **System-level audits find the highest-impact issues.** Cycle 15's integration audit found the #1 problem (nothing wired) that 5 prior code-level cycles missed entirely.
- **Alternate system-level and code-level research.** Code-level finds bugs; system-level finds "it doesn't work at all." Both are necessary.
- **Comparing code vs docs is high-yield.** Cycle 2 found 5 critical/high issues by diffing code against PIPELINE.md, QUERIES.md.
- **Comparing code vs schema is equally high-yield.** health.ts had 4 broken SQL issues found this way.
- **Reading error handling paths (catch blocks) finds more than scanning for missing try/catch.**
- **Testing actual imports vs test assertions catches phantom tests.** Always check import statements.
- **Targeted deep-dives on previously-audited modules still pay off.**
- **Identify systemic cross-cutting issues.** Timezone handling emerged as a pattern affecting multiple files.
