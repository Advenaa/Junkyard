## Critical

### [D-001] SSRF: Webhook URL not validated before delivery
- **Location**: `src/deliver/webhook.ts:288-300`
- **Category**: security
- **Description**: webhook_url from DB passed directly to fetch() without SSRF validation. fetchValidated() exists but is not used. Admin can set to internal IPs.

### [D-002] SSRF: URL expansion bypasses SSRF protection
- **Location**: `src/normalize/url-expand.ts:36-52`
- **Category**: security
- **Description**: expandUrl uses raw fetch() to follow short URL redirects. No private IP check. Attacker-controlled t.co link can redirect to cloud metadata.

### [D-003] pg_dump credential leak + wrong CLI usage
- **Location**: `src/ops/backup.ts:33`
- **Category**: security
- **Description**: Full DATABASE_URL passed as positional arg (exposed in ps aux). Also, pg_dump treats positional arg as dbname, not connection string — backup is broken.

### [D-004] Translation prompt injection — no nonce wrapping
- **Location**: `src/normalize/index.ts:140-147`
- **Category**: security
- **Description**: Raw user content sent to Haiku translation LLM without XML nonce wrapping. Injection patterns can survive the heuristic regex scan.
