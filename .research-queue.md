# Fix Queue — Podders v2

## Critical

- **CS-001** — Chat semantic search missing prepareText() prefix. `src/chat/tools.ts:49` calls `embedder.embed(query)` directly, but embed-pipeline stores vectors via `embedder.prepareText(text, type)` which adds "summary: " prefix. Query vectors and stored vectors have different prefixes → cosine similarity degraded. Fix: prepare query text with type prefix before embedding.

## High

- **CS-002** — No minimum similarity threshold in vector search. `src/vector-cache.ts:108-122` returns all results including near-zero and negative scores. Sparse cache returns garbage results. Fix: add MIN_SIMILARITY ~0.5 filter.
- **SC-001** — Daily catch-up time overflow for late-night digest. `src/index.ts:293` computes catchUpTime that can produce "24:01" for digest_time 23:56+. String comparison with toLocaleString (max "23:59") always false → catch-up never fires. Fix: wrap hours with `% 24`.
- **SD-001** — Webhook delivery leaves reports pending forever when webhook_url not configured. `src/deliver/webhook.ts:294-296` returns false without calling updateDeliveryStatus. Fix: mark as 'failed'.
- **SD-005** — Narratives detected AFTER daily synthesis. `src/index.ts:269` runs narrativeDetector after synthesizer.runDaily(). Daily report lacks narrative context (emerging/strong/fading signals). Fix: reorder — run embedPipeline + narratives before synthesis, pass narratives to runDaily().
- **EL-001** — Empty alias pollution in entity_aliases. `src/knowledge/entities.ts:324-326` pushes normalizeAlias(alias) without checking for empty string. normalizeAlias("$") → "". Fix: add `if (!normalizedAlias) continue`.
- **NP-001** — Translation nonce-only content corruption. `src/normalize/index.ts:173-176` fallback `cleaned || result.content` can pass through bare nonce tags if LLM returns only tags. Fix: add minimum length check after nonce stripping.
- **DP-003** — Infinite retry loop for failed summarizer items. `src/process/summarize.ts:545-553` resets failed items to 'ready' with no retry counter. Items that always fail LLM burn budget indefinitely. Fix: track retry count, mark 'failed' after 3 attempts.
- **DP-001** — Pre-summarizer content_anchor atomicity gap. `src/pre-summarize/index.ts:121+134` sets anchor before content update. Crash between them → item invisible to pre-summarizer forever. Fix: set anchor only after successful content update.

## Medium

- **EL-002** — Decay/retention ordering. Retention deletes mentions, then decay checks last_seen. Can archive entities that had recent mentions. Fix: decay should check for recent mentions before archiving.
- **EL-003** — Summary inserted before entity resolution. `src/process/summarize.ts:481-506` inserts summary, then resolves entities. Error in resolution → orphaned summary with no entity_mentions. Fix: resolve entities first.
- **EL-004** — Tier 1 alias lookup ignores entity type. `src/knowledge/entities.ts:80-90` queries by alias only, not type. Same alias pointing to token vs project → nondeterministic. Fix: join entities table and filter by type.
- **EL-005** — Context-aware aliases cause multi-row Tier 1 lookups. Same alias with different context_keys → rows[0] nondeterministic. Fix: add type filter or LIMIT with deterministic ordering.
- **SD-002** — Correlator instantiated twice. `src/process/synthesize.ts:338` creates new correlator instead of using global from index.ts. Fix: inject correlator into synthesizer.
- **SD-006** — Correlator sourceId field contains summary ID, not source ID. `src/process/correlate.ts:119` assigns `summaryIds[0]`. Fix: remove field or populate correctly.
- **NP-002** — Race condition in content hash dedup under concurrency. Early SELECT can pass for both threads; ON CONFLICT handles it but no audit trail. Low risk, document.
- **NP-003** — Missing content re-validation after translation failure. `src/normalize/index.ts` catch block doesn't re-check minimum length. Fix: add length validation in catch.
- **DP-004** — Discord queue overflow drops messages silently. No DB record of drops. Fix: write health_event or filtered item record.
- **CS-004** — Vector cache loads all-time vectors, evicts recent in long-running systems. Fix: limit to last 30 days.
- **CS-005** — Entity embeddings never populated by pipeline. Vector cache has 'entity' map but embed-pipeline skips entities. Fix: add entity embedding or remove map.
- **CS-006** — Indonesian translation fallback breaks search. 3x length check too strict, falls back to Indonesian query without re-embedding. Fix: improve validation threshold or return error.
