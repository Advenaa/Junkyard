### [P-001] Empty/whitespace content passes all normalize gates — inserted as 'ready'
- **Location**: `src/normalize/index.ts`
- **Description**: Empty string, whitespace-only, or multi-emoji content survives all 6 gates for non-Discord sources. Gets claimed by summarizer, wastes LLM tokens.

### [P-002] Discord heartbeat setTimeout leak on reconnect
- **Location**: `src/ingest/discord.ts:469-489`
- **Description**: clearHeartbeat only clears the setInterval, not the jitter setTimeout. Rapid reconnects stack orphaned setInterval timers. Each fires every ~41s, holds a closure, may send on dead sockets.

### [P-003] Embed pipeline has no overlap guard — double execution wastes Gemini quota
- **Location**: `src/embed-pipeline.ts` (called from both onSourcePollTick and onDaily)
- **Description**: No mutex or running flag. If onDaily fires while a poll-tick embed is running, both execute simultaneously, embedding the same summaries twice.
