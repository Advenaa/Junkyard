## High

### [LM-008] Timeout errors not retried in LLM wrapper
- **File**: `src/llm.ts:360-365`
- **Category**: reliability
- **Description**: Network timeouts (ETIMEDOUT, AbortError) fall through to "unknown error" path and are not retried. Timeouts are transient and should retry.
- **Fix**: Detect timeout via error code/message, retry with backoff.

### [LM-004] Cost calculation doesn't validate cost.total presence
- **File**: `src/llm.ts:243`
- **Category**: data-integrity
- **Description**: `response.usage.cost.total` accessed without null check. If provider doesn't populate cost, undefined/NaN gets inserted to DB.
- **Fix**: Add null-coalescing: `const cost = response.usage.cost?.total ?? 0;`

### [RS-001] RSS parser not hardened against XXE
- **File**: `src/ingest/rss.ts:61`
- **Category**: security
- **Description**: RssParser instantiated without security config. No protection against XXE or entity expansion attacks in feed XML.
- **Fix**: Pass xml2js options to disable external entities if rss-parser supports it, or validate/sanitize XML before parsing.

### [RS-002] RSS feed URL not SSRF-validated
- **File**: `src/ingest/rss.ts:62`
- **Category**: security
- **Description**: Feed URL passed directly to rss-parser.parseURL() without SSRF validation. Article extraction uses fetchValidated() but feed fetch itself bypasses it.
- **Fix**: Pre-fetch with fetchValidated() and pass response to parser, or validate URL before parseURL.

## Medium

### [LM-002] Exponential backoff too aggressive (128s max delay)
- **File**: `src/llm.ts:341`
- **Category**: reliability
- **Description**: `2000 * Math.pow(4, attempt)` produces delays up to 128s. Total wait ~253s for persistent 5xx. Too aggressive.
- **Fix**: Change base to Math.pow(2, attempt) for max ~16s delay.

### [LM-003] Nonce entropy too low (32 bits)
- **File**: `src/llm.ts:391`
- **Category**: security
- **Description**: crypto.randomBytes(4) = 32 bits. Birthday collision risk at ~65k items.
- **Fix**: Increase to crypto.randomBytes(8) for 64-bit nonce.

### [RS-011] Relative URLs in RSS feeds not resolved
- **File**: `src/ingest/rss.ts:111`
- **Category**: data-integrity
- **Description**: RSS items with relative URLs (e.g., /article/123) stored as-is. Breaks URL dedup, dashboard links, and article extraction.
- **Fix**: Resolve relative URLs against feed URL using `new URL(link, feedUrl)`.

### [EM-004] Stale embeddings not replaced on summary update
- **File**: `src/embed-pipeline.ts:96`
- **Category**: data-integrity
- **Description**: INSERT ... ON CONFLICT DO NOTHING means updated summaries keep old embeddings. Vector search returns stale results.
- **Fix**: Change to ON CONFLICT DO UPDATE SET vector = EXCLUDED.vector, created_at = EXCLUDED.created_at.

### [EM-007] 429 Retry-After header parsing incorrect in embedder
- **File**: `src/embed.ts:87-96`
- **Category**: reliability
- **Description**: Tries to extract retry-after from statusText (human-readable string), not actual header. Always falls back to 60s default.
- **Fix**: Check error object for retryAfter property or use default. Remove broken regex.

### [AU-007] OAuth state not tracked server-side (reuse possible)
- **File**: `src/auth/discord-oauth.ts:47-54, 84-98`
- **Category**: security
- **Description**: OAuth state is stored only in cookie, not server-side. Can be replayed within 10-minute window.
- **Fix**: Track consumed states in an in-memory Set with 10-minute TTL.

### [AU-010] Session limit race condition
- **File**: `src/auth/sessions.ts:63-80`
- **Category**: data-integrity
- **Description**: Concurrent logins can create more than MAX_SESSIONS_PER_USER (5). No transaction or lock on session eviction.
- **Fix**: Wrap in BEGIN/FOR UPDATE/COMMIT transaction.

### [CH-008] Token budget resets on restart (in-memory only)
- **File**: `src/chat/handler.ts:127-149`
- **Category**: reliability
- **Description**: User daily token budgets stored in-memory Map. Restart resets all limits.
- **Fix**: Persist to llm_usage table. Deferred from cycle 65.
